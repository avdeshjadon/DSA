# Data Structures & Algorithms (DSA)

This repository is my practice ground for **Data Structures and Algorithms**, implemented in **Java**.

## What is DSA?

DSA is the study of how data is organized (data structures) and how it is processed (algorithms). It is the foundation of efficient problem solving in computer science.

- **Data Structures** — ways to store and organize data (arrays, linked lists, stacks, queues, trees, graphs, hash tables, heaps, etc.)
- **Algorithms** — step-by-step procedures to solve problems (searching, sorting, recursion, dynamic programming, etc.)

Good DSA knowledge leads to code that is:

- **Faster** — better time complexity
- **Lighter** — better space complexity
- **Scalable** — handles large inputs without breaking down

## Why practice DSA?

- Core requirement in technical interviews
- Improves logical thinking and problem-solving ability
- Foundation for building performant software
